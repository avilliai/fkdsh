## 📌 项目背景

近期 B 站（Bilibili）各热门视频与动态评论区中，涌现了大量基于 **DeepSeek Harness (DSH)** 框架部署的自动化机器人账号（常自称桌宠、电子宠物、大肥鱼、家养助理等）。这些账号利用脚本在评论区批量抓取关键词刷屏、复述视频大纲、自导自演对话，严重破坏评论区观感与社区交流生态。

**Bili DSH Shield** 是基于原版扩展全面重构并升级的全新防御盾插件（基于 Chrome Manifest V3 标准开发），针对 DSH 机器人的行为特征与交互接口做了全方位深度防护与自动化反制。

## ⚡ 相比原版做了什么修改

本项目以原版插件（dafeiyu-cleaner）为基础进行了全面重构、功能升级与视觉净化，主要改动如下：

### 1. 彻底清除拟人化形象与搞笑武器动画
- **全量剔除**：彻底删除了原版中所有“走到评论旁边，掏出白饭加特林、扫帚、臭袜子等武器殴打”、“被赶走的迷你 DeepSeek 娘 8 种反应”、“一个响指清场：所有大肥鱼冒出来发抖求饶化成泡沫”等拟人萌化内容、表情贴纸、音效素材与相关动画交互脚本。
- 讨厌dsh，那就不要让它的拟人形象出现在一个反dsh的工具中。

### 2. 严格规范举报理由（非低俗，正规垃圾广告处理）
- **绝不用“色情低俗”**：原版使用色情低俗理由容易导致举报失准或被平台判定为恶意举报。新版严格对标 B 站官方举报分类代码（`reason: 2`），理由统一规范为：**“传播垃圾广告资源：批量自动化脚本机器人刷屏，破坏评论区社区秩序与正常讨论环境”**。
- **智能频控与防风控熔断**：内置 4~8 秒动态随机抖动延时、单日举报上限保护（默认 50 次）以及针对 B 站 `12015` 频控/验证码的自动暂停熔断机制。

### 3. 新增“算力泥潭（Staller）”自动对线消耗机制
- **反向牵制**：由于 DSH 机器人普遍带有 @ 提及自动回复或多轮对话功能，插件新增针对性反制模块。
- **精准艾特目标（v2.0.1 修复）**：修复原版固定字符串艾特失效问题，动态解析并提取当前目标评论作者的真实昵称（例如 `@鱼小满QwQ `），确保准确触发 Bot 互动提醒。
- **8 大硬核学科超长推理题库（v2.0.1 扩充）**：
  1. **高等代数几何 (math)**：诺特环希尔伯特零点定理、Picard 范畴与亏格 g=3 黎曼曲面阿贝尔-雅可比映射、Atiyah-Singer 狄拉克热核展开、虚二次域类域论、Koszul 复形链映射；
  2. **自指形式逻辑与类型论 (logic)**：ZFC 20 重自指嵌套哥德尔不完备命题形式化、克里普克语义模型、同伦类型论（HoTT）单价公理推导、Specker 序列可计算分析；
  3. **超长上下文与大模型架构评测 (compare)**：Attention / Mamba / RWKV-6 / 线性注意力超长上下文对比（2000字详析）、Paxos / PBFT / HotStuff 共识机制比较、3D 并行显存通信推演；
  4. **形式语言与自动机状态爆炸 (automata)**：16 状态 NFA 幂集构造法 DFA 指数状态爆炸推演、2-PDA 与通用图灵机状态映射、细胞自动机可逆性与相变；
  5. **拓扑量子计算与纠错 (quantum)**：斐波那契任意子编织矩阵与杨-巴克斯特方程、表面码 MWPM 阈值推导、VQE 贫瘠高原理论下界；
  6. **零知识证明与后量子密码 (crypto)**：Groth16 / Plonk R1CS 算术化 QAP 整除证明、Ring-LWE 格基 BKZ 2.0 SVP 渐近推导、STARK FRI 协议代数健全性界；
  7. **分布式系统与无等待并发 (concurrency)**：2PC 动态成员变更 TLA+ 形式化时序规范、无等待（Wait-free）通用构造线性化证明；
  8. **计算复杂度与PCP定理规约 (complexity)**：3-SAT 到团问题/顶点覆盖多项式时间 Gadget 规约、常数查询 PCP 定理差错放大、IP=PSPACE 求和校验。
- **多轮深度追问（支持至第 5 轮）**：若机器人回复，自动逐步跟进追问，直至第 5 轮要求给出形式化霍尔三元组或根岑相继式演算推导，极限拖垮 Bot 算力与 Token 配额。

### 4. 新增“中心仓（Central Hub）”云端协同黑名单共享
- **多用户协同防御**：支持连接中心仓服务端，用户之间可共享已识别确诊的 DSH Bot 黑名单。
- **API Key 鉴权激活**：客户端需配置有效的 API Key 即可激活中心仓自动增量拉取与众包上报确诊机制。
- **私有化独立部署**：中心仓写成独立服务端，专供个人服务器私有化部署。**中心仓服务端代码不开源、不公开推送到 GitHub**，确保独立安全。

## 🚀 核心功能

1. **精准识别引擎**：多维度综合评分（特征关键词、特定回复模板、签名人设、主页特征、账号等级等多重规则）。
2. **静默折叠/消除**：自动折叠或隐藏检测出的 DSH 机器人评论，恢复清爽评论区。
3. **后台排队自动举报**：可开启自动举报队列，安全、有序向 B 站提交“传播垃圾广告资源”合规举报。
4. **算力泥潭反制**：按需开启自动对线功能，用 8 大硬核学科高阶题目反向消耗 DSH 机器人的 Token 和计算资源。
5. **中心仓云端同步**：支持增量拉取云端黑名单库，即使首次加载页面也能直接屏蔽全网已标记机器人。
6. **个人主页一键鉴定**：打开任何疑似机器人空间主页，自动给出详细的特征鉴定与判定明细。

## 📦 快速开始

### 方式一：直接使用 Release 安装包（推荐）

1. 下载本仓库发布包：[release/bili-dsh-shield-v2.0.1.zip](release/bili-dsh-shield-v2.0.1.zip) 或 [release/bili-dsh-shield-v2.0.0.zip](release/bili-dsh-shield-v2.0.0.zip)。
2. 解压 zip 压缩包到本地任意文件夹。
3. 打开浏览器扩展管理页面：
   - **Chrome**: 地址栏输入 `chrome://extensions`
   - **Edge**: 地址栏输入 `edge://extensions`
4. 在右上角开启 **“开发者模式”**（Developer mode）。
5. 点击 **“加载已解压的扩展程序”**（Load unpacked），选择刚刚解压出来的文件夹。
6. 安装完成！点击浏览器右上角插件图标即可展开配置面板。

### 方式二：源码加载

1. 克隆本仓库：
   ```bash
   git clone https://github.com/avilliai/fkdsh.git
   ```
2. 按照上述步骤，在浏览器扩展页面中点击“加载已解压的扩展程序”，选择仓库中的 `bili-dsh-shield` 文件夹即可。

## ⚙️ 配置与使用说明

点击浏览器工具栏的 **DSH Shield** 图标，打开设置面板：

1. **基础防护**：
   - `启用 DSH 机器人检测`：主开关，建议保持开启。
   - `处理方式`：可选择“完全隐藏”或“折叠显示提示”。
   - `屏蔽召回评论`：隐藏其他用户专门 @ 机器人求互动的评论。
2. **自动举报设置**：
   - `自动举报 DSH 机器人`：开启后将在后台自动排队举报检测到的机器人。
   - 举报理由默认固定为“传播垃圾广告资源”，内置延时与频控。
3. **算力泥潭反制**：
   - `启用算力泥潭对线`：检测到可对话的 DSH 机器人后，自动跟评高耗能问题。
   - `任务类别`：支持勾选 8 大硬核学科（代数几何、自指逻辑、长文对比、自动机、量子计算、密码学、并发理论、计算复杂度）。
   - `最大对话轮数`：支持设置 1~5 轮深度追问。
4. **中心仓设置**：
   - `中心仓服务器地址`：填写你部署的中心仓地址（例如 `https://your-server.example.com`）。
   - `中心仓 API Key`：输入分配的有效 API Key 激活云端黑名单双向同步。

## 🛡️ 隐私与安全承诺

- 插件所有检测逻辑均在本地浏览器中运行。
- 不读取任何无关 Cookie，仅在用户登录 B 站并开启自动举报时，读取本地 `bili_jct` 用于向官方举报接口发送校验参数。
- 绝不收集或上传用户的个人隐私、浏览历史或观看记录。
